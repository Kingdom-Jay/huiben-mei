# 回本没

> 基金套牢了？一键算一算，要投入多少才能回本。

一个**纯静态单文件**的基金回本测算工具：上传持仓截图自动 OCR 识别全部基金，支持「一次性买入补仓」与「定投摊薄」两种模式，逐基金列出回本情况并汇总所需资金。

打开即用，无需安装、无需后端。

## ✨ 功能特性

| 功能 | 说明 |
|---|---|
| 多张截图 OCR | 基于 Tesseract.js 浏览器端识别中文，支持一次上传多张持仓截图 |
| 多基金自动提取 | 从截图中批量解析每只基金的名称、持有金额、持有收益；自动跳过"金选/定投"等标签行，支持跨行名称合并与"联接C"等份额后缀拼接 |
| 持仓列表编辑 | 识别结果进入可编辑列表，支持手动添加、修改、删除 |
| 一次性买入模式 | 输入预期第二日涨幅，计算回本所需补仓资金 |
| 定投模式 | 输入每日定投金额与目标持有收益率（负数且需优于当前），计算摊薄成本所需天数 |
| 回本情况清单 | 逐基金列出亏损额、需补仓资金/所需天数、补仓后成本，并汇总合计 |
| 实时重算 | 首次计算后修改任意输入自动更新结果，支持回车触发 |

## 🚀 使用方法

1. 下载或克隆本仓库；
2. 用浏览器直接打开 `back.html`（双击即可）；
3. 上传基金持仓截图（如蚂蚁财富/天天基金 App 的"我的持有"页面），等待识别完成；
4. 核对/修正基金列表，选择投资模式并填写参数；
5. 点击计算，查看每只基金的回本情况与汇总。

> OCR 语言包通过 CDN 加载，首次识别需联网；识别结果请人工核对，OCR 可能存在误读。

## 🧮 计算模型

设 `M` = 持有金额（当前市值），`P` = 持有收益（亏损为负），`I = M - P` = 初始投入本金。

### 一次性买入模式

输入预期第二日涨幅 `r`，求补仓资金 `X` 使次日反弹后回本：

```
(M + X) × (1 + r) = I + X
X = (|P| - M × r) / r
```

- `X ≤ 0`：预期涨幅足以覆盖亏损，无需补仓；
- 已盈利（`P ≥ 0`）的基金不参与补仓计算。

### 定投模式

假设单位净值不变，每日定投 `D`，求摊薄到目标收益率 `r_target`（负数）所需天数 `n`：

```
P / (I + n × D) = r_target
n = (P / r_target - I) / D   （向上取整）
```

## 📸 识别效果

对包含 5 只基金的真实持仓截图（列合并、跨行名称、标签行混排）可完整提取名称、持有金额与持有收益，逐基金输出回本清单。识别结果支持手动修正。
